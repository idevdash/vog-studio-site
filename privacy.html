Privacy Policy

VOG Studio · last updated 17 September 2026

VOG Studio is a personal tool with a single user: its author. It runs on his own computer. There is no server, no account system, no other user, and no way for anyone else to use it.

What it stores, and where

Everything the application keeps is stored in a folder on the author's own computer. Nothing is uploaded to any server operated by this application, because there is no such server.

  • A Google sign-in token, so it can post on the author's behalf without asking him to sign in each time.
  • Public video information — titles, dates and durations from a public YouTube channel.
  • Automatic captions that YouTube publishes for those public videos, and English translations of them.
  • Comments it has written, and a record of which have been approved and posted.

What it accesses on YouTube, and why

The application requests permission to manage the signed-in user's YouTube account. It uses that permission only to:

  • post comments and replies as the signed-in user
  • like videos as the signed-in user
  • read back its own posted comments to check they are visible

It does not read the user's private data, watch history, subscriptions, or any other account information, and it does not modify anything else.

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Third parties

One part of the application sends text to a third party: the caption text of public sermon videos is sent to an AI language model provider in order to translate it and to draft comments from it. That text comes from publicly published videos. No account data, no sign-in token, and no personal information is ever sent.

Nothing is sent to advertisers, analytics services or data brokers. The application contains no tracking of any kind.

Sharing

No data is shared with anyone. There is nobody to share it with.

Retention and deletion

Data stays in a folder on the author's computer until he deletes it. Deleting that folder removes everything. Google access can be revoked at any time at myaccount.google.com/permissions, which immediately ends the application's ability to act on the account.

Children

The application is not directed at children and has no users other than its author.

Changes

If this policy changes, the date at the top of this page changes with it.

Contact

Questions about this policy can be sent to the email address registered as the developer contact on the application's Google Cloud project.
